常用设置

学生名单管理（当前 人）

方式一：用 Excel/WPS 打开名单 xlsx → 全选复制（Ctrl+C）→ 粘贴到下面框 → 点导入。
方式二：点击按钮选择 CSV 文件。格式：学号、姓名、性别（列顺序不限，自动识别表头）。

数据管理

数据存储在设备本地。换机/升级前请先导出备份。

检查更新

默认自动检查 GitHub 仓库最新 Release（无需配置）；也可填写自定义 version.json 地址覆盖。检测到新版本后点击链接下载新 APK 安装即可。
